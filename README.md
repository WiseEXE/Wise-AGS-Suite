# 🐧 Wise-AGS-Suite

Welcome to my first major Linux project! 

This suite is a completely custom desktop interface built using **AGS (Aylur's GTK Shell)**. Like many others, my interest in Linux was sparked by the incredible setups on **r/UnixPorn**. Being a DIY enthusiast, I decided to skip the pre-made themes and build my own environment from the ground up.

### 🛠 The Mission
The goal of this repository is to create a functional, aesthetic, and cohesive UI suite for my Arch Linux setup. Since I am learning **JavaScript** and **TypeScript** as I go, this project serves as both my daily driver and my personal classroom. 

### 🚀 Tech Stack
* **Engine:** [AGS](https://github.com/Aylur/ags) (GJS/GTK)
* **Logic:** TypeScript
* **Styling:** SCSS
* **WM:** Hyprland

> [!NOTE]  
> Progress will be slow but steady. As I grow my coding skills, I'll be refactoring and adding features. Feedback from the community is always appreciated!
